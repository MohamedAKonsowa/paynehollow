# Payne Hollow Virtual Tour

An interactive virtual tour experience of Payne Hollow on the Ohio, created to help preserve and share the historical, artistic, and ecological significance of the site.

This project presents Payne Hollow through an immersive web-based experience, allowing users to explore the location digitally through panoramic scenes, interactive navigation, and responsive tour controls. The tour is hosted through GitHub Pages and can be viewed directly in a browser.

## Live Demo

View the project here:

https://mohamedakonsowa.github.io/paynehollow/

## About the Project

Payne Hollow is a historic property located along the Ohio River in Trimble County, Kentucky. It is closely associated with Harlan and Anna Hubbard, who lived there for decades and became known for their simple, self-sufficient lifestyle, artistic work, writings, and connection to the natural environment.

This virtual tour was developed to make the site more accessible to students, researchers, community members, and the public. By presenting Payne Hollow digitally, the project helps support education, storytelling, preservation, and community engagement around the site.

## Project Features

- Web-based interactive virtual tour
- 360° panoramic scene navigation
- Responsive layout for desktop and mobile viewing
- Custom tour interface and media assets
- Browser-based access through GitHub Pages
- Static deployment with no backend required

## Technologies Used

- 3DVista Virtual Tour Pro
- HTML
- CSS

- GitHub Pages
